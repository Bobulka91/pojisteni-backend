# Evidence pojištění – Backend

Spring Boot REST API pro webovou aplikaci evidence pojištěnců a jejich pojištění.

## Tech Stack

| Vrstva | Technologie |
|---|---|
| Backend | Spring Boot 4 |
| Jazyk | Java 17 |
| Databáze | MySQL |
| ORM | Spring Data JPA (Hibernate) |
| Build tool | Maven |
| Ostatní | Lombok |

## Funkce

- REST API endpointy pro správu pojištěnců (CRUD)
- REST API endpointy pro správu pojištění (CRUD)
- Persistence dat přes Spring Data JPA a MySQL
